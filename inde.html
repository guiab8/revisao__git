Principais Atalhos do VS Code

Ação / Descrição Atalho (Windows/Linux)
Paleta de Comandos Ctrl + Shift + P ou F1
Busca Rápida de Arquivos Ctrl + P
Busca Global no Projeto Ctrl + Shift + F
Abrir / Fechar Terminal Ctrl + ` (crase)
Mostrar / Ocultar Barra Lateral Ctrl + B
Comentar / Descomentar Linha Ctrl + /
Formatar Documento Shift + Alt + F
Duplicar Linha para Cima/Baixo Shift + Alt + Setas
Mover Linha para Cima/Baixo Alt + Setas
Deletar Linha Atual Ctrl + Shift + K
Selecionar Próxima Ocorrência Igual Ctrl + D
Renomear Símbolo / Variável F2
